# 00 环境搭建（Linux / 4090 服务器）

## 目标

在一台 Ubuntu + NVIDIA 驱动 + CUDA 的 4090（24GB）服务器上，搭建可以训练、评测、部署本项目的环境。

## 1. 基础要求

- Ubuntu 22.04+（或 20.04），`nvidia-smi` 能正常输出（驱动已装好）；
- 磁盘 ≥ 50GB（数据 + checkpoint）；
- 能访问 HuggingFace 或 ModelScope（国内服务器见下方镜像说明）。

## 2. 一键初始化

```bash
bash deploy/server_setup.sh
```

脚本会安装：基础工具（git/tmux/htop）、uv、Python 3.11 虚拟环境 `.venv`、
CUDA 版 PyTorch、项目依赖与 vLLM，最后验证 `torch.cuda.is_available()`。

之后每次登录服务器：

```bash
cd AhaModel
source .venv/bin/activate
pip install -e .   # 首次需要；之后改代码无需重装
```

## 3. 数据下载（国内服务器）

HuggingFace 在国内可能不稳定，两种方案：

```bash
# 方案 A：使用镜像
export HF_ENDPOINT=https://hf-mirror.com
python scripts/02_prepare_data.py --stage all

# 方案 B：ModelScope 手动下载
# 打开 https://www.modelscope.cn/datasets/gongjy/minimind_dataset
# 下载 pretrain_t2t_mini.jsonl / sft_t2t_mini.jsonl / dpo.jsonl / rlaif.jsonl
# 放到 data/ 下并重命名为 pretrain.jsonl / sft.jsonl / dpo.jsonl / rlaif.jsonl
```

## 4. 长任务与可视化

```bash
# tmux：断开 SSH 也不中断
tmux new -s train
python scripts/03_pretrain.py --use-logger swanlab   # Ctrl+B D 脱离
tmux attach -t train

# 可视化：SwanLab（国内友好，wandb 兼容接口）
export SWANLAB_API_KEY=...
python scripts/04_sft.py --use-logger swanlab
```

也可用 `--use-logger wandb` / `--use-logger tensorboard`。

## 5. 常见问题

- **CUDA 版本不匹配**：按驱动装对应 PyTorch，如 `pip install torch --index-url https://download.pytorch.org/whl/cu124`；
- **显存不够**：调小 `batch_size` 并用 `grad_accum` 补足有效 batch；64M 模型在 24GB 上很宽裕；
- **CPU 也能跑**：`--smoke` 模式专为无 GPU 环境设计；正式训练建议 GPU。
