# 04 预训练：next-token prediction

## 1. 任务定义

预训练就是最大化 `P(x_{t+1} | x_1..x_t)`：给定前文预测下一个 token。
整个语料变成「输入 + 右移一位的标签」，模型用交叉熵学习。

## 2. 数据组织

`PretrainDataset` 每行 `{"text": ...}` 编码为 token 序列，截断到 `max_seq_len`，
collate 时右 padding（`<|pad|>`），标签在 pad 位置设为 -100（不参与 loss）。

## 3. 训练循环（`ahamodel/train/trainer.py`）

一个工程化训练循环包含：

- **混合精度**：GPU 上 bf16 优先（数值稳），不支持时回退 fp16 + GradScaler；
- **梯度累积**：`batch_size × grad_accum` 才是有效 batch，小显存也能跑大 batch；
- **学习率**：warmup 线性上升 + 余弦退火（手写，不引第三方 scheduler）；
- **梯度裁剪**：`grad_clip=1.0` 防止 loss spike；
- **断点续训**：`latest.pt` 保存 model/optimizer/step，`--from-resume` 恢复；
- **可视化**：`--use-logger tensorboard|swanlab|wandb`。

## 4. 运行

```bash
# smoke 验证（CPU 几分钟）
python scripts/03_pretrain.py --smoke

# 正式（4090）
python scripts/03_pretrain.py --use-logger swanlab
```

默认超参在 `configs/pretrain.yaml`：`batch_size=8, grad_accum=8, lr=3e-4,
warmup=200, max_seq_len=768`。

## 5. 怎么看训练是否正常

- **loss 曲线**：应平滑下降；突然 spike 通常是大 batch + 高 lr，可调 `grad_clip`；
- **PPL 参考**：64M 模型在 mini 语料上训练末期 PPL 约 20~50 属正常（见 docs/09）；
- **生成检查**：`python scripts/10_eval.py samples --model-path checkpoints/pretrain/latest.pt`
  应能产出语法通顺但未必「懂道理」的文本。

## 6. 常见问题

- **loss 不降**：lr 太小 / 数据为空 / tokenizer 词表与模型不一致（脚本会自动对齐）；
- **显存不足**：调小 batch_size，用 grad_accum 补；或换 `configs/model_26m.yaml`；
- **训练太慢**：确认用了 CUDA、bf16 生效（日志 device=cuda）。

## 扩展思路

- 用 Swin-like 数据打包（packing）代替截断，减少 padding 浪费；
- 加入 DDP 多卡（`torchrun --nproc_per_node=2`，本项目单卡为主）；
- 记录 26M/64M/150M 的训练曲线做 Scaling Law 小实验。
