# 01 数据准备与清洗

> 流程顺序：**数据准备与清洗（本步）→ Tokenizer 训练（docs/02）→ 预训练**。
> 词表必须基于清洗后的真实语料训练，因此本步排在最前。

## 1. 为什么清洗

「垃圾进，垃圾出」。原始网络文本包含 HTML 标签、URL、重复段落、无意义短文，
直接训练会浪费算力、污染分布。清洗管线（`ahamodel/data/clean.py`）：

```text
原始文本 -> html.unescape + 去标签 -> 去 URL/控制字符 -> 空白归一化
        -> 长度过滤(50~10000) -> 中文占比过滤 -> sha256 全文去重 -> {"text": ...} jsonl
```

## 2. 两条数据路径

### 路径 A：快速路径（推荐）

直接使用 `jingyaogong/minimind_dataset` 已清洗好的 mini 系列：

```bash
python scripts/01_prepare_data.py --stage all
# 产物: data/pretrain.jsonl(1.2GB) data/sft.jsonl(1.6GB) data/dpo.jsonl data/rlaif.jsonl
```

### 路径 B：教学路径（理解清洗本身）

从 HF 拉中文 Wikipedia 子集，现场演示「脏数据 → 干净数据」：

```bash
python scripts/01_prepare_data.py --stage wiki --wiki-n 10000
```

把产物改名合并到 `data/pretrain.jsonl` 即可走同一套下游流程。

## 3. 质量过滤指标

`quality_filter(text, min_len, max_len, min_cjk_ratio)`：

- **长度**：太短没有学习价值，太长超出 max_seq_len 会被截断浪费；
- **中文占比 `min_cjk_ratio`**：`\u4e00-\u9fff` 字符占比，滤掉非目标语言段落；
- **去重**：全文 sha256，流式处理不占内存。

## 4. 抽样与规模控制

4090 上默认跑全量 mini 数据（预训练约 1~2h）。想先验证：

```bash
python scripts/01_prepare_data.py --stage pretrain --max-lines 20000
```

## 5. 常见问题

- **下载失败**：国内服务器设 `export HF_ENDPOINT=https://hf-mirror.com`，或走 ModelScope 手动下载；
- **语料太杂**：先看清洗前后的字符分布（`docs/09` 的 PPL 也能侧面反映数据质量）。

## 扩展思路

- 用 MinHash 做近重复去重（大规模语料更有效）；
- 按困惑度/质量模型打分过滤（如 fastText 语言分类）；
- 加入 PII 脱敏规则。
